# Spec Delta

## ADDED Requirements

### Requirement: Categorias con metadata
El panel de administracion SHALL permitir editar el icono y el color de cada categoria.

#### Scenario: Editar categoria
- **WHEN** el administrador edita una categoria
- **THEN** puede elegir icono y color y se reflejan en el formulario

#### Scenario: Nueva categoria
- **WHEN** el administrador crea una categoria
- **THEN** puede asignarle icono, color y si requiere ubicacion
